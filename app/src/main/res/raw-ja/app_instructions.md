# NCM コンバーター — 使い方ガイド

## 一、アプリ概要
**NCM コンバーター**は、NetEase Cloud Music（網易雲音楽）で暗号化された `.ncm` ファイルを標準的な **MP3** / **FLAC** 音声ファイルに復号・復元できる無料の Android ツールです。

> すべての復号処理は端末内のローカル環境で完結し、ファイルがインターネット上にアップロードされることは一切ありません。

---

## 二、対応形式
- **NetEase Cloud Music**：`.ncm`

---

## 三、使用手順
1. **「NCMファイルを選択」** ボタンをタップし、ファイルマネージャーから 1 つ以上の `.ncm` ファイルを選択します。
2. ファイル右側の再生ボタンをタップして個別に復号するか、画面下部の **「すべて変換」** をタップして一括処理します。
3. 復号完了後、保存ボタンをタップしてストレージに書き込みます（**自動保存**が有効な場合は自動的に保存されます）。
4. 画面上部の歯車アイコンをタップして **設定** を開くと、保存先パスやテーマ、フォントなどをカスタマイズできます。

---

## 四、設定項目について
- **保存先パス**：復号後のファイルの保存場所を設定します（デフォルトは `Music/NCMConverter`）。
- **自動保存**：有効にすると変換完了後に自動保存され、バックグラウンド変換（通知バーでの進捗表示）も有効になります。無効にすると変換後に手動で保存ボタンをタップします。
- **カバー自動取得**：有効にすると変換時にネットワークからアルバムカバー画像を自動取得します。
- **テーマとカラー**：**システム / ライト / ダーク** の 3 モード、**Material You** ダイナミックカラー（Android 12+）、および **HSL** スライダーによるカスタムカラーに対応しています。
- **システムフォント**：端末にインストールされているシステムフォントを検出し、全体のフォントウェイト（`100`〜`900`）を自由に調整できます。

---

## 五、歌詞機能（公式 API 直接接続内蔵）
歌詞の自動埋め込み機能には NetEase 公式 API への暗号化直接接続が内蔵されており、外部サーバーを別途構築することなくそのまま利用できます。

### 歌詞設定について
- **歌詞自動埋め込み**：有効にすると変換時に歌詞を自動検索して埋め込みます。
- **原文歌詞を埋め込む**：出力ファイルに原文の歌詞を含めます。
- **翻訳歌詞を埋め込む**：出力ファイルに翻訳歌詞を含めます（原文と翻訳の両方を有効にした場合、行ごとに自動で結合されます）。

### 歌詞の埋め込み形式
- **MP3 ファイル**：`USLT`（非同期歌詞）ID3v2 タグに書き込みます。
- **FLAC ファイル**：`LYRICS` Vorbis Comment フィールドに書き込みます。

---

## 六、技術仕様
- `AES-128-ECB` によるキーブロックおよびメタデータの復号
- 改良型 `RC4` アルゴリズムによる音声データの復号
- 出力フォーマット（`MP3` / `FLAC`）の自動判別
- 楽曲メタデータ（タイトル、アーティスト、アルバム、カバーアート）の自動書き込み
- 複数の歌詞マッチング戦略に対応（`musicId` による直接検索、曲名＋アーティスト名での検索）

---

## 七、注意事項
- 1 回につき最大 **50** 個の `.ncm` ファイルを選択できます。`.ncm` 以外のファイルはインポート時に自動で除外されます。
- 大容量ファイルの復号には時間がかかる場合がありますので、そのままお待ちください。
- 復号後の音声形式は元のファイルデータによって決まり、通常は `MP3` または `FLAC` となります。
- 変換に失敗する場合は、ファイルが破損していないか、有効な `.ncm` ファイルであるかをご確認ください。
- Android 10 以降では `MediaStore` / `DocumentFile` API を使用してファイルを安全に保存します（Android 17 / API 37 まで完全対応）。
- 歌詞およびカバーの取得にはインターネット接続が必要です。取得に失敗しても音声ファイルの復号自体には影響しません。

---

## 八、プライバシーポリシー
- すべてのファイル復号処理はお使いの端末ローカルで行われます。
- アプリがファイルや音声データをインターネットにアップロードすることはありません。
- カバー画像および歌詞を取得する際のみネットワークにアクセスします。
- アプリはいかなる個人情報も収集しません。

## 九、よくある質問（FAQ）
**Q: 変換後のファイルに曲名が付かないのはなぜですか？**
A: 一部の古いバージョンの `.ncm` ファイルではメタデータ情報が不完全な場合があります。音声データ自体には影響ありません。

**Q: 一括変換（バッチ変換）には対応していますか？**
A: はい。最大 50 個のファイルを選択して **「すべて変換」** をタップすることで一括変換できます。

**Q: 変換後のファイルはどこに保存されますか？**
A: デフォルトでは `Music/NCMConverter` フォルダに保存されます。設定画面から変更可能です。

**Q: 歌詞機能が使えません。**
A: アプリには NetEase 公式 API への暗号化直接接続が内蔵されています。端末のインターネット接続をご確認ください。

**Q: 歌詞が見つからないのはなぜですか？**
A: 考えられる原因：
1. NetEase Cloud Music 上に該当曲の歌詞が存在しない
2. ネットワーク接続エラー
3. 一部の海外ネットワークにおける地域制限
