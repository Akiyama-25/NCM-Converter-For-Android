NCM 轉換器 — 使用說明
======================

一、應用簡介
-----------
NCM 轉換器是一款免費的 Android 工具，可將網易雲音樂加密的 .ncm 檔案解密還原為標準 MP3/FLAC 音訊檔案。

所有解密計算均在手機本機完成，不會上傳您的任何檔案到網路。

二、支援格式
------------
- 網易雲音樂：.ncm

三、使用步驟
-----------
1. 點選「選擇 NCM 檔案」按鈕，從檔案管理器中選擇一個或多個 .ncm 檔案
2. 點選檔案右側的播放按鈕開始解密，或點選底部的「全部轉換」批次處理
3. 解密完成後點選儲存按鈕將檔案寫入儲存空間（或等待自動儲存）
4. 點選頂欄齒輪圖示進入設定，可自訂匯出路徑、主題、字型等

四、設定說明
-----------
- 儲存路徑：設定解密後的檔案儲存位置，預設為 Music/NCMConverter
- 自動儲存：開啟後轉換完成自動儲存，並支援背景轉換與通知欄進度顯示；關閉後需手動點選儲存按鈕
- 自動取得封面：開啟後轉換時自動從網路下載歌曲封面
- 主題與顏色：支援跟隨系統 / 淺色 / 深色三種模式、Material You 動態取色（Android 12+）以及自訂 HSL 強調色與背景色
- 系統已安裝字型：支援掃描並切換本機系統字型，並提供 100–900 全域字重調節

五、歌詞功能（內建官方直連）
----------------------------------
歌詞自動嵌入功能已內建網易雲官方直連支援，開箱即用，無需自行架設外部伺服器。

歌詞設定說明：
- 自動嵌入歌詞：開啟後轉換時自動搜尋並嵌入歌詞
- 歌詞模式：
  · 嵌入原文歌詞：輸出檔案中包含原文歌詞
  · 嵌入翻譯歌詞：輸出檔案中包含翻譯歌詞（若同時勾選原文與翻譯，將自動逐行對齊合併）

歌詞嵌入格式：
- MP3 檔案：寫入 USLT（非同步歌詞）ID3v2 標籤
- FLAC 檔案：寫入 LYRICS Vorbis Comment 欄位

六、技術細節
-----------
- 使用 AES-128-ECB 解密金鑰區塊和中繼資料
- 使用改良 RC4 演算法解密音訊資料
- 自動偵測輸出格式（MP3/FLAC）
- 自動寫入歌曲中繼資料（標題、藝術家、專輯、封面）
- 歌詞取得支援多種比對策略（musicId 直接尋找、歌曲名+歌手搜尋）

七、注意事項
-----------
- 每次最多可選擇 50 個 .ncm 檔案，匯入時會自動過濾非 .ncm 檔案
- 大檔案解密可能需要較長時間，請耐心等待
- 解密後的音訊格式由原始檔案決定，通常為 MP3 或 FLAC
- 如果轉換失敗，請確認檔案未損壞且為有效的 NCM 檔案
- Android 10+ 使用 MediaStore / DocumentFile API 儲存檔案
- 歌詞與封面取得需要網路連線，取得失敗不影響音訊檔案轉換

八、隱私聲明
-----------
- 所有檔案解密均在您裝置本機完成
- 應用不會上傳任何檔案或音訊資料到網際網路
- 僅在取得封面圖片和歌詞時會存取網路
- 應用不收集任何個人資訊

九、常見問題
-----------
Q: 為什麼轉換後的檔案沒有歌曲名？
A: 部分舊版本 .ncm 檔案的中繼資料資訊不完整，音訊資料本身不受影響。

Q: 支援批次轉換嗎？
A: 支援。您可以選擇最多 50 個檔案後點選「全部轉換」。

Q: 轉換後的檔案儲存在哪裡？
A: 預設儲存在 Music/NCMConverter 目錄下，可在設定中修改。

Q: 歌詞功能無法使用？
A: 客戶端已內建網易雲官方加密直連，請檢查裝置網路連線是否正常。

Q: 為什麼沒有找到歌詞？
A: 可能原因：1) 歌曲在網易雲音樂無歌詞 2) 網路連線異常 3) 部分海外網路受地域限制
