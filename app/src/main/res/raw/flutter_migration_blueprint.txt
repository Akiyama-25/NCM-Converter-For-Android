NCM 转换器 · Flutter 三端 (Android / Windows / iOS) 移植与 M3E 系统字体技术方案
================================================================================

1. 架构概览 (Pure Dart + Isolate × FlClash M3E)
------------------------------------------------
• 跨端核心引擎：纯 Dart 实现 AES-128-ECB 密钥解包、RC4 流式异或解密、MP3 ID3v2.3 / FLAC Vorbis Comment & Picture 元数据写入，以及网易云官方 WeAPI/EAPI 加密直连。
• 多线程并发调度：采用 Isolate.run 与常驻 Worker Isolate 池并发处理音频流，按 ≥2% 粒度节流回传进度，保证 120Hz UI 满帧渲染。
• 零内嵌字体方案：彻底移除 ~45MB 的内嵌字体包，运行时直接扫描并加载操作系统已安装字体（Android SystemFonts & /system/fonts、Windows C:\Windows\Fonts、iOS UIFont.familyNames），支持搜索预览与 100–900 九档字重调节。

2. Material 3 Expressive (M3E) × FlClash 视觉规范
-------------------------------------------------
• 容器色阶：采用 surfaceContainerLowest -> surfaceContainerHighest 多层表面容器构建分组卡片（圆角 20dp–28dp），替代传统分割线。
• 响应式导航：
  - Compact (<600dp)：顶部 M3E 状态仪表盘 + 底部悬浮胶囊操作栏 + AOSP 预见性返回手势。
  - Medium / Expanded (≥600dp，平板/折叠屏/Windows 桌面)：自适应多列网格 (1–5 列) 与双栏分组设置面板。
• 弹簧物理动效：列表入场、状态徽章切换与底部面板均采用低阻尼弹簧曲线 (Spring.DampingRatioLowBouncy)。

3. 三端专属交互适配
-------------------
• Windows 桌面端：
  - 集成 desktop_drop 支持拖入单个/多个 .ncm 文件或整个文件夹递归导入。
  - 集成 window_manager 与 tray_manager 支持最小化到系统托盘后台常驻转换。
• iOS 移动端：
  - 开启 UIFileSharingEnabled 与 LSSupportsOpeningDocumentsInPlace，无缝对接系统「文件 (Files)」App。
  - 声明 .ncm UTI 文档类型与 Share Sheet 扩展，支持从微信、网盘或文件管理器「用其他应用打开」直接导入。
• Android 移动端：
  - 保留 SAF (DocumentTree) 目录权限持久化与 Foreground Service 前台服务通知栏实时转换进度。
